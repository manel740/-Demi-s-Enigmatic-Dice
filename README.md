# Enigmatic Dice

A Minecraft mod that adds enigmatic dice featuring epic random events, powerful items, and unique mechanics.

## Information
- **Minecraft Version:** 1.21.1
- **Loader:** NeoForge 21.1.73+
- **Mod Version:** 1.3.1-1.21.1

## ✨ Features

### Enigmatic Dice
- Unique random events upon rolling the die
- Over 30 different events (summons, buffs, debuffs, transformations)
- Configurable probability system

### Powerful Items
- **Gravity Core**: Control gravity and perform epic jumps
- **Soul Eater**: Sword that absorbs souls and gains power
- **Moon & Moon Shard**: Manipulate lunar gravity
- **Crucible of Rile**: Legendary weapon with special attacks
- **Divine Shield**: Shield granting temporary invulnerability
- **Ring of Agility**: Increases speed and agility
- **Yomu**: Sword with unique animations
- **Permafrost**: Freezes enemies

### Custom Attribute System
- Unique attributes for each item
- Custom status effects
- Persistent player data

## 📦 Requirements

- **Curios API** (required)

## 🚀 Installation

1. Install **NeoForge** for Minecraft 1.21.1
2. Download **Curios API**
3. Place the `enigmatic-dice-1.3.1-1.21.1.jar` file in the `mods` folder
4. Enjoy! ## 🎮 Usage

- Enigmatic Dice can be obtained from the creative inventory
- Right-click to roll the die and trigger a random event
- Items can be crafted or found in the creative inventory
